## Acceptance checklist

- [ ] The intended existing/new project owns the repository; duplicate projects and overview documents were avoided.
- [ ] The checkout resolves to that project without an explicit --project override; registered Repo URL and local marker agree.
- [ ] Useful existing instructions and unrelated working changes are preserved.
- [ ] The project overview and codebase guide contain checked facts, real paths and relevant constraints.
- [ ] Configured agent tools load their shared project guidance; a fresh-session orientation check has been observed.
- [ ] Project-specific findings are filed in the owning Library; cross-project conventions are filed in memory.
- [ ] Project context and recall retrieve useful knowledge; trust, citation and index limitations are recorded.
- [ ] Appropriate validation commands have been run and results recorded against the inspected code.
- [ ] Handoff/next steps are recorded; all required acceptance checks pass before completion.

Procedure: [Set up a repository and its Prax project](/starter-content/repository-setup.md). Use the Project overview starter for the owning project. Link the resulting overview to the task.

Complete only when acceptance checks pass. Update task notes before handing over; preserve reusable findings in the owning Library.
