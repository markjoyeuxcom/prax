# Performance evidence

Raw files in this directory are generated by `npm run measure:performance` and retain their
`candidate-baseline-only` state. A separate `prax.performance-budget` manifest may propose or,
after explicit human attestation, approve thresholds for one exact reference-hardware class.

Do not edit raw measurement values or treat a proposal as a release gate. An approved manifest
gates only through a fresh compatible `npm run gate:performance` measurement.
